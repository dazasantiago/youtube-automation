# HyperFrames — Esquema del video

**Semana:** 2026-W28 · **Slug:** hyperframes · **Generado:** 2026-07-09

## Ángulo / tesis

HyperFrames apuesta a que el video se escribe, no se edita — eso cambia quién puede producir
contenido: cualquier agente que sepa escribir HTML ya sabe hacer video.

## Hook (apertura)

Mostrar un prompt de una línea convirtiéndose en un video renderizado, antes de explicar qué es
HyperFrames.

## Estructura

### 1. Qué es HyperFrames y por qué HTML-to-video (media)

- Renderiza HTML/CSS/animaciones seekable a MP4 determinístico
- Pensado para que lo use un agente de código, no un editor humano
